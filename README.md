# Netflix Supporter

넷플릭스가 표시한 오프닝·지난 줄거리·다음 회차 버튼을, 클릭 가능한 시점에 자동으로 누르는 가벼운 Chrome 확장 프로그램입니다.

목표는 **인위적인 대기 없이 정확한 버튼만 한 번 누르기**입니다. 영상 분석, 광고 건너뛰기, 자막 수집, 추천 서비스는 포함하지 않습니다.

개인 프로젝트이며 Netflix와 제휴하거나 Netflix가 제공하는 공식 제품이 아닙니다.

## 개발 범위

- Manifest V3 기반의 Chrome 확장 프로그램
- 전체 및 종류별 켜기/끄기, 설정은 기기에만 저장
- 오프닝·지난 줄거리 건너뛰기
- 추천작과 구분되는 다음 회차 버튼 자동 클릭
- 중복 클릭 방지와 회차 전환 대응

## 개발 이력

이 저장소는 검토 가능한 작업 단위로 개발합니다. 첫 커밋은 프로젝트 범위와 작업 규칙만 담으며, 실행 코드는 기능 브랜치와 PR로 추가합니다.

1. 감지 엔진, 오프닝·줄거리 스킵, 관련 테스트와 CI
2. 다음 회차 이동 및 전환 안정성
3. 설정 UI, 배포 패키지, 사용·설계·검증 문서

현재 실제 Netflix 재생 환경 검증은 완료되지 않았습니다. 모의 화면 검증과 실제 서비스 검증은 별도로 기록합니다.
