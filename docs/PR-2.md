## 문제와 변경된 동작

엔딩에서 다음 회차를 자동 재생하되, 본편 도중의 도구 모음이나 마지막 회차 뒤 추천 작품을 잘못 누르지 않도록 전용 post-play hook 두 개만 허용합니다.

## 의존성

`codex/instant-skip-engine`을 기반으로 한 두 번째 PR입니다. 첫 PR 이후의 다음 회차 판별·테스트만 포함합니다.

## 검증

이 브랜치에서 타입 검사, 34개 테스트, 빌드 통과. 전용 다음 회차 두 종류, 카운트다운 hook 변경, 추천작·도구 모음 제외, 회차 교체 후 오프닝 감지 복구를 확인했습니다.

## 한계

허용하지 않은 hook을 클릭하지 않는 것은 모의 환경에서 확인했습니다. 실제 Netflix의 마지막 회차/일반 회차 UI 검증은 별도 필요합니다. 엔딩 뒤 추가 장면을 분석하는 기능은 없습니다.
