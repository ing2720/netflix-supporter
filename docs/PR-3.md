## 문제와 변경된 동작

종류별 자동 스킵 제어와 직접 설치를 위해 한국어 설정창, 로컬 저장, 설치 ZIP과 문서를 추가합니다. 영상 위 UI와 추가 대기는 넣지 않았습니다.

## 의존성 / 범위

`codex/next-episode-navigation`을 기반으로 한 세 번째 PR입니다. 전체 OFF 동안 숨김/재등장한 재사용 버튼도 다시 ON 할 때 처리하도록 상태 초기화와 회귀 테스트를 추가했습니다.

- 네 개의 스위치, 저장 실패 복구, 초기 읽기/변경 이벤트 경합 처리
- 실제 코어·UI를 사용하는 모의 플레이어와 Chrome 13개 시나리오 확인
- 한국어 설치법, 구조·결정 기록, 검증 범위와 실제 미확인 항목
- ZIP/체크섬, 이 저장소의 정해진 브랜치와 Draft PR만 게시하는 수동 실행 도구
