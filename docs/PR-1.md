## 문제와 변경된 동작

오프닝·지난 줄거리 버튼이 켜졌을 때 사용자가 직접 누르거나 주기적 검색을 기다리는 불편을 줄입니다. DOM 변경을 감지하고 인식된 버튼이 표시·활성 상태이면 인위적인 대기 없이 클릭합니다.

## 범위

- Manifest V3, TypeScript 빌드와 읽기 권한만 사용하는 CI
- 활성화·조상 숨김·화면 밖 상태 확인, 같은 표시 구간 및 즉시 재생성 버튼 중복 억제
- 저장된 OFF 존중, SPA 진입 및 전환 이벤트 처리
- 타이머·외부 런타임 의존성·네트워크 요청 없음

## 검증

이 브랜치에서 타입 검사, 23개 jsdom 회귀 테스트, 프로덕션 빌드 통과. content.js 3,950 bytes. 관계없는 자막 변경은 후보의 클릭 가능 상태를 다시 계산하지 않는 테스트 포함.
